Setup and daily use

  1. Run the independent desktop updater. It creates an ArcusAttribution / reports folder in your local application data.
  2. Connect that reports folder here, or import its arcus-attribution.json file.
  3. Select two funds and dates covered by your archive. Use the latest completed price date.
  4. If data is missing, update the archive or import verified return levels. Arcus sign-in provides access to this page; your financial archive is still imported privately.

Folder permission may be requested again after reopening. The website cannot start a desktop program or update Bloomberg for you.
