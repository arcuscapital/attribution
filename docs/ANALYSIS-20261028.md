## Changes

- 17 ETF additions, yielding 64 ETFs plus four portfolios. Source dates, counts and public source URLs: `analysis-fund-additions-20261028.json`. Existing 51 remote allocations are copied exactly into the new generation; raw allocations/backups remain private. Some additions use September/early October snapshots, explicitly dated. IJR preserves issuer market weights, derives only missing weights from reported market values, and discloses the basis. No notional-weight substitution or normalization.
- Searchable theme groups, bold group headings, portfolios first; Arcus's stored USD daily returns with exact Arcus green/red colors and dates. This authenticated D1 read adds no collector.
- Higher-contrast regular Segoe UI/Arial, tabular numbers, separate company names and column boundaries. Security return precedes active weight in the website and Excel. White unfilled Excel body cells, black Calibri, visible gridlines, existing headers and freeze panes.
- Retry missing prices bypasses both caches for affected listed holdings and their FX, then replaces successful cached results. Requests remain on demand, at most two concurrent. It cannot create cash income or private valuations.
- Taiwan cash-equity holidays for 2026 from the official TWSE calendar, verified 2026-10-28. Exact `.TW`/TWD/Asia-Taipei identity required. Prior open-session adjusted close carries across verified closures only; FX still requires the actual valuation date. Tokyo 2026/2027 remains supported. Missing open days and unsupported calendars/years stay unavailable. Maintain calendars when exchanges publish each new year; the TWSE 2027 query currently returned 2026 and was deliberately not accepted as 2027 evidence.
- Explicit unchecked-by-default 0% missing-period-return assumption, in the selected currency. Every assumed holding is labelled on screen and in Excel; original measured coverage and missing-data disclosure remain. Contributions use average opening weight times period return, ETFs retain observed reference returns, sector attribution is withheld. This is not proof of a holiday or a complete measured return.
